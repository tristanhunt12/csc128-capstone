# College Program and Career Path Assistant

This is my CSC-128 capstone project for Central Piedmont Community College.

The purpose of this chatbot is to help current or future Central Piedmont students explore programs based on their interests, career goals, and preferred type of work.

## Features

The chatbot supports four main intents:

1. Recommend Central Piedmont programs based on student interests and career goals
2. Explain a specific program and the careers it can lead to
3. Compare two Central Piedmont programs
4. Explore career options related to a specific program

The chatbot also maintains conversation context, collects user information through follow-up questions, uses an LLM for natural-language responses, and includes error handling when it does not know an answer.

## Technologies Used

- Python
- Streamlit
- Groq API
- GitHub
- Central Piedmont program information
